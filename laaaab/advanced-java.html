1 Objective

  • To create a simple Java Swing application
  • To connect the Swing application with an SQL database
  • To understand tools, drivers, and steps required for JDBC connectivity

2 Theory

Java Swing is a GUI (Graphical User Interface) toolkit used to build desktop applications in Java. To connect a Swing application with an SQL database, JDBC (Java Database Connectivity) is used.

JDBC is an API that allows Java programs to connect and execute queries on databases such as MySQL, PostgreSQL, or SQLite.

Tools Used:

  • Java JDK – To write and run Java programs
  • IDE (Eclipse / IntelliJ / NetBeans)
  • MySQL Database – To store and retrieve data
  • JDBC Driver (MySQL Connector/J)
  • Swing Components – JFrame, JButton, JTextField, JLabel

Steps to Connect Swing with Database:

  1. Install MySQL and create a database
  2. Add MySQL JDBC Driver to the project
  3. Import required JDBC packages
  4. Load the JDBC driver
  5. Create a connection using DriverManager
  6. Execute SQL queries using PreparedStatement
  7. Display result in Swing UI
  8. Close the database connection

3 Code

Database Table

CREATE DATABASE studentdb;

USE studentdb;

CREATE TABLE students (
    id INT PRIMARY KEY,

Java Swing Program with JDBC 

import javax.swing.*;
import java.awt.event.*;
import java.sql.*;

public class SwingDBExample {

    public static void main(String[] args) {
        JFrame frame = new JFrame("Swing Database Connection");

        JLabel lblId = new JLabel("ID:");
        lblId.setBounds(20, 20, 80, 25);

        JTextField txtId = new JTextField();
        txtId.setBounds(100, 20, 150, 25);

        JLabel lblName = new JLabel("Name:");
        lblName.setBounds(20, 60, 80, 25);

        JTextField txtName = new JTextField();
        txtName.setBounds(100, 60, 150, 25);

        JButton btnSave = new JButton("Save");
        btnSave.setBounds(100, 100, 80, 30);

        frame.add(lblId);
        frame.add(txtId);
        frame.add(lblName);
        frame.add(txtName);
        frame.add(btnSave);

        btnSave.addActionListener(new ActionListener() {
            public void actionPerformed(ActionEvent e) {
                try {
                    Class.forName("com.mysql.cj.jdbc.Driver");

                    Connection con = DriverManager.getConnection(
                        "jdbc:mysql://localhost:3306/studentdb",
                        "root",
                        "password"
                    );

                    String sql = "INSERT INTO students VALUES (?, ?)";
                    PreparedStatement ps = con.prepareStatement(sql);

                    ps.setInt(1, Integer.parseInt(txtId.getText()));
                    ps.setString(2, txtName.getText());

                    ps.executeUpdate();

                    JOptionPane.showMessageDialog(frame, "Data Inserted Successfully");

                    con.close();
                } catch (Exception ex) {
                    JOptionPane.showMessageDialog(frame, ex.getMessage());
                }
            }
        });

        frame.setSize(350, 200);
        frame.setLayout(null);
        frame.setVisible(true);
        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
    }
}

1 Objective

  • To create a Java program that connects to a database using JDBC
  • To perform insert, update, delete, and display operations on employee records
  • To understand menu-driven programming with database interaction
  • To gain practical knowledge of CRUD operations in Java

2 Theory

Java Database Connectivity (JDBC) is an API that enables Java applications to interact with relational databases such as MySQL. JDBC provides classes and interfaces to establish a connection with the database, execute SQL queries, and process the results.

A menu-driven program allows users to choose different operations at runtime. In this experiment, JDBC is used to perform CRUD (Create, Read, Update, Delete) operations on an employee table using SQL queries.

3 Code

Employee Table (Database Setup – for reference)

CREATE DATABASE company;

USE company;

CREATE TABLE employee (
    id INT PRIMARY KEY,
    name VARCHAR(50),
    salary DOUBLE,
    branch VARCHAR(50)
);

Java Program (Menu-Driven JDBC)

import java.sql.*;
import java.util.Scanner;

public class Employee {

    String url = "jdbc:mysql://localhost:3306/company?useSSL=false&serverTimezone=UTC";
    String user = "root";
    String password = "12345";

    Connection con = null;
    Statement stmt = null;
    ResultSet rs = null;
    Scanner sc = new Scanner(System.in);

    void connect() throws Exception {
        con = DriverManager.getConnection(url, user, password);
        stmt = con.createStatement();
    }

    void insertEmployee() {
        try {
            connect();
            System.out.print("Enter ID: ");
            int id = sc.nextInt();
            System.out.print("Enter Name: ");
            String name = sc.next();
            System.out.print("Enter Salary: ");
            double salary = sc.nextDouble();
            System.out.print("Enter Branch: ");
            String branch = sc.next();

            String query = "INSERT INTO employee VALUES (" + id + ",'" + name + "'," + salary + ",'" + branch + "')";
            stmt.executeUpdate(query);
            System.out.println("Employee Inserted Successfully!");
            con.close();
        } catch (Exception e) {
            System.out.println(e);
        }
    }

    void updateSalary() {
        try {
            connect();
            System.out.print("Enter ID: ");
            int id = sc.nextInt();
            System.out.print("Enter New Salary: ");
            double salary = sc.nextDouble();

            String query = "UPDATE employee SET salary=" + salary + " WHERE id=" + id;
            stmt.executeUpdate(query);
            System.out.println("Salary Updated!");
            con.close();
        } catch (Exception e) {
            System.out.println(e);
        }
    }

    void updateName() {
        try {
            connect();
            System.out.print("Enter ID: ");
            int id = sc.nextInt();
            System.out.print("Enter New Name: ");
            String name = sc.next();

            String query = "UPDATE employee SET name='" + name + "' WHERE id=" + id;
            stmt.executeUpdate(query);
            System.out.println("Name Updated!");
            con.close();
        } catch (Exception e) {
            System.out.println(e);
        }
    }

    void updateBranch() {
        try {
            connect();
            System.out.print("Enter ID: ");
            int id = sc.nextInt();
            System.out.print("Enter New Branch: ");
            String branch = sc.next();

            String query = "UPDATE employee SET branch='" + branch + "' WHERE id=" + id;
            stmt.executeUpdate(query);
            System.out.println("Branch Updated!");
            con.close();
        } catch (Exception e) {
            System.out.println(e);
        }
    }

    void deleteEmployee() {
        try {
            connect();
            System.out.print("Enter ID: ");
            int id = sc.nextInt();

            String query = "DELETE FROM employee WHERE id=" + id;
            stmt.executeUpdate(query);
            System.out.println("Employee Deleted!");
            con.close();
        } catch (Exception e) {
            System.out.println(e);
        }
    }

    void displayEmployees() {
        try {
            connect();
            String query = "SELECT * FROM employee";
            rs = stmt.executeQuery(query);

            System.out.println("ID\tName\tSalary\tBranch");
            while (rs.next()) {
                System.out.println(
                        rs.getInt("id") + "\t" +
                        rs.getString("name") + "\t" +
                        rs.getDouble("salary") + "\t" +
                        rs.getString("branch")
                );
            }
            con.close();
        } catch (Exception e) {
            System.out.println(e);
        }
    }

    public static void main(String[] args) {

        Employee emp = new Employee();
        Scanner sc = new Scanner(System.in);
        int choice;

        do {
            System.out.println("\\nEnter your choice...");
            System.out.println("1. Insert employee");
            System.out.println("2. Update salary");
            System.out.println("3. Update name");
            System.out.println("4. Update branch");
            System.out.println("5. Delete employee");
            System.out.println("6. Display all employee");
            System.out.println("7. Exit");

            choice = sc.nextInt();

            switch (choice) {
                case 1: emp.insertEmployee(); break;
                case 2: emp.updateSalary(); break;
                case 3: emp.updateName(); break;
                case 4: emp.updateBranch(); break;
                case 5: emp.deleteEmployee(); break;
                case 6: emp.displayEmployees(); break;
                case 7: System.out.println("Exiting Program..."); break;
                default: System.out.println("Invalid Choice!");
            }
        } while (choice != 7);
    }
}

1 Objective

  • To create a stored procedure in a database
  • To call the stored procedure from a Java program using JDBC
  • To insert person details into a database table using a stored procedure

2 Theory

A stored procedure is a set of SQL statements stored in the database and executed as a single unit. Stored procedures improve performance, security, and reusability of database operations.

In Java, stored procedures are executed using CallableStatement, which is a part of JDBC. It allows Java programs to pass parameters to the database and execute predefined SQL logic.

Advantages of Stored Procedures:

  • Faster execution
  • Better security
  • Code reusability
  • Reduced SQL injection risk

3 Code

Database Setup – Employee Table

CREATE DATABASE company;
USE company;

CREATE TABLE employee (
    id INT PRIMARY KEY,
    name VARCHAR(50),
    age INT,
    address VARCHAR(100)
);

Stored Procedure

DELIMITER $$

CREATE PROCEDURE insertPerson(
    IN pid INT,
    IN pname VARCHAR(50),
    IN page INT,
    IN paddress VARCHAR(100)
)
BEGIN
    INSERT INTO employee VALUES (pid, pname, page, paddress);
END $$

DELIMITER ;

Java Program (Calling Stored Procedure)

import java.sql.*;
import java.util.Scanner;

public class Person {

    String url = "jdbc:mysql://localhost:3306/company?useSSL=false&serverTimezone=UTC";
    String user = "root";
    String password = "12345";

    public void insertPerson() {
        try {
            Connection con = DriverManager.getConnection(url, user, password);
            CallableStatement cs = con.prepareCall("{call insertPerson(?,?,?,?)}");

            Scanner sc = new Scanner(System.in);

            System.out.print("Enter ID: ");
            cs.setInt(1, sc.nextInt());

            System.out.print("Enter Name: ");
            cs.setString(2, sc.next());

            System.out.print("Enter Age: ");
            cs.setInt(3, sc.nextInt());

            System.out.print("Enter Address: ");
            cs.setString(4, sc.next());

            cs.execute();

            System.out.println("Person Record Inserted Successfully!");

            con.close();
        } catch (Exception e) {
            System.out.println(e);
        }
    }

    public static void main(String[] args) {
        Person p = new Person();
        p.insertPerson();
    }
}

1 Objective

  • To understand the concept of scrollable ResultSet in JDBC
  • To demonstrate updating database records using an updatable ResultSet
  • To learn how Java can navigate and modify database records dynamically

2 Theory

In JDBC, a ResultSet represents data retrieved from a database. By default, a ResultSet is forward-only and read-only. JDBC provides special ResultSet types that allow scrolling and updating of records.

Scrollable ResultSet

A scrollable ResultSet allows moving the cursor:

  • Forward
  • Backward
  • To a specific row
  • To the first or last row

This is achieved using:
ResultSet.TYPE_SCROLL_INSENSITIVE

Updatable ResultSet

An updatable ResultSet allows modifying database records directly from Java without writing SQL UPDATE statements.

This is achieved using:
ResultSet.CONCUR_UPDATABLE

Common Cursor Methods:

  • next()
  • previous()
  • first()
  • last()
  • absolute(int row)
  • updateXXX()
  • updateRow()

3 Code

Database Table (Example)

CREATE TABLE employee (
    id INT PRIMARY KEY,
    name VARCHAR(50),
    salary DOUBLE
);

Java Program

import java.sql.*;

public class ScrollableUpdatableRS {

    public static void main(String[] args) {
        try {
            String url = "jdbc:mysql://localhost:3306/company?useSSL=false&serverTimezone=UTC";
            String user = "root";
            String password = "12345";

            Connection con = DriverManager.getConnection(url, user, password);

            Statement stmt = con.createStatement(
                    ResultSet.TYPE_SCROLL_INSENSITIVE,
                    ResultSet.CONCUR_UPDATABLE
            );

            ResultSet rs = stmt.executeQuery("SELECT * FROM employee");

            // Scrollable ResultSet
            System.out.println("First Record:");
            rs.first();
            System.out.println(rs.getInt(1) + " " + rs.getString(2) + " " + rs.getDouble(3));

            System.out.println("Last Record:");
            rs.last();
            System.out.println(rs.getInt(1) + " " + rs.getString(2) + " " + rs.getDouble(3));

            // Move to specific row
            rs.absolute(2);
            System.out.println("Second Record:");
            System.out.println(rs.getInt(1) + " " + rs.getString(2) + " " + rs.getDouble(3));

            // Updatable ResultSet
            rs.updateDouble("salary", 50000);
            rs.updateRow();
            System.out.println("Salary Updated Successfully!");

            con.close();
        } catch (Exception e) {
            System.out.println(e);
        }
    }
}

1 Objective

  • To create a JavaBean class with properties
  • To understand JavaBean conventions such as no-argument constructor and getter/setter methods
  • To use the BeanInfo interface to display properties and methods of a JavaBean

2 Theory

A JavaBean is a reusable software component written in Java. JavaBeans are commonly used in component-based development and frameworks.

JavaBean Conventions:

  • It must have a public no-argument constructor
  • All properties must be private
  • It must provide public getter and setter methods
  • It should be serializable (optional but recommended)

BeanInfo Interface:

The BeanInfo interface is part of the java.beans package. It provides information about a JavaBean such as:

  • Properties
  • Methods
  • Events

The Introspector class is used to obtain the BeanInfo object of a JavaBean.

3 Code

JavaBean Class (User.java)

import java.io.Serializable;

public class User implements Serializable {

    private String username;
    private int age;
    private String address;

    // No-argument constructor
    public User() {
    }

    // Getter and Setter methods
    public String getUsername() {
        return username;
    }

    public void setUsername(String username) {
        this.username = username;
    }

    public int getAge() {
        return age;
    }

    public void setAge(int age) {
        this.age = age;
    }

    public String getAddress() {
        return address;
    }

    public void setAddress(String address) {
        this.address = address;
    }
}

BeanInfo Demonstration Program

import java.beans.*;

public class BeanInfoDemo {

    public static void main(String[] args) {
        try {
            BeanInfo beanInfo = Introspector.getBeanInfo(User.class);

            System.out.println("Bean Class Name:");
            System.out.println(beanInfo.getBeanDescriptor().getName());

            System.out.println("\\nProperties:");
            PropertyDescriptor[] properties = beanInfo.getPropertyDescriptors();
            for (PropertyDescriptor pd : properties) {
                System.out.println(pd.getName());
            }

            System.out.println("\\nMethods:");
            MethodDescriptor[] methods = beanInfo.getMethodDescriptors();
            for (MethodDescriptor md : methods) {
                System.out.println(md.getName());
            }

        } catch (Exception e) {
            System.out.println(e);
        }
    }
}

1 Objective

  • To understand the concept of serialization and deserialization in Java
  • To serialize a JavaBean object and store it in a file
  • To deserialize the object and retrieve the stored data
  • To learn how Java supports object persistence

2 Theory

Serialization is the process of converting an object into a byte stream so that it can be stored in a file or transmitted over a network. Deserialization is the reverse process of converting the byte stream back into an object.

In Java, serialization is achieved by:

  • Implementing the Serializable interface
  • Using ObjectOutputStream to write objects to a file
  • Using ObjectInputStream to read objects from a file

JavaBean and Serialization:

  • The class must follow JavaBean conventions
  • The class must implement the Serializable interface

Classes Used:

  • Serializable
  • FileOutputStream
  • FileInputStream
  • ObjectOutputStream
  • ObjectInputStream

3 Code

Serialization and Deserialization Program

import java.io.*;

public class SerializationDemo {

    public static void main(String[] args) {

        try {
            // Create User object
            User u = new User();
            u.setUsername("Ram");
            u.setAge(22);
            u.setAddress("Kathmandu");

            // Serialization
            FileOutputStream fos = new FileOutputStream("user.txt");
            ObjectOutputStream oos = new ObjectOutputStream(fos);
            oos.writeObject(u);
            oos.close();
            fos.close();

            System.out.println("Object Serialized Successfully!");

            // Deserialization
            FileInputStream fis = new FileInputStream("user.txt");
            ObjectInputStream ois = new ObjectInputStream(fis);
            User userObj = (User) ois.readObject();
            ois.close();
            fis.close();

            System.out.println("\\nDeserialized Object Data:");
            System.out.println("Username: " + userObj.getUsername());
            System.out.println("Age: " + userObj.getAge());
            System.out.println("Address: " + userObj.getAddress());

        } catch (Exception e) {
            System.out.println(e);
        }
    }
}
